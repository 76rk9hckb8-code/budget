# Семейный Бюджет (PWA)

Умное мобильное веб-приложение для ведения общего семейного бюджета, накопления подушки безопасности и финансовой грамотности.

## Возможности
- 📱 **PWA для iPhone и Android**: Устанавливается на главный экран как нативное приложение.
- 🔌 **Офлайн-режим**: Работает без интернета, сохраняя данные локально и синхронизируя их при появлении сети.
- ☁️ **Синхронизация через Google Диск**: Общий доступ для вас и супруги/супруга.
- 📷 **Сканер чеков и PDF-выписок**: Автоматический разбор трат и анализ расходов.
- 🎯 **Умные цели и подушка безопасности**: Помогает распределять деньги и учит финансовой грамотности.

## Как запустить и выложить на GitHub Pages:
1. Создайте новый репозиторий на GitHub (например, `family-budget`).
2. Загрузите все файлы из этого архива (`index.html`, `manifest.json`, `sw.js`, `README.md`) в репозиторий.
3. В настройках репозитория перейдите в раздел **Pages**, выберите ветку `main` (или `master`) и нажмите **Save**.
4. Через минуту GitHub выдаст ссылку на ваше приложение (например, `https://yourusername.github.io/family-budget/`).
5. Откройте эту ссылку в Safari на iPhone, нажмите кнопку «Поделиться» -> «На экран "Домой"».
